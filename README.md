# Digital Design with FPGA

Short workshop on digital circuit design with synthesizable SystemVerilog on the Sipeed Tang Nano 20K, using VS Code and the open-source toolchain. Each level is an independent course.
Modules are taken one at a time.

Open `index.html` in a browser (works over `file://`, no server, no CDN).

| Folder | Content | Status |
|---|---|---|
| `0-Configuration/` | Module 0: setup and first design on the board | The blink example builds and loads to the board from Windows and from WSL (LED behaviour to be confirmed by the author). Setup scripts for Windows/WSL/Linux/macOS and an AI setup prompt in `scripts/` and `ai-setup-prompt.md` |
| `project-template/` | Starting project for every lab (Makefile, src, tb, constraints) | done |
| `1-Basic/` | Level 1 | modules 1.1 to 1.6 and 7 labs done (first version, awaiting feedback) |
| `2-Intermediate/` | Level 2 | planned |
| `3-Advanced/` | Level 3 | planned |
| `shared/` | CSS, JS, and highlight.js shared by every page | |
