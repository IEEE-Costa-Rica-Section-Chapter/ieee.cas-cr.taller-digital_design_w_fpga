Digital Design with FPGA

Learn to design digital circuits in synthesizable SystemVerilog and run them on a real Sipeed Tang Nano 20K, using VSCode and a fully open-source toolchain. Each level is an independent course. Start with Module 0 to set up your workstation.

SystemVerilog Tang Nano 20K Open-source tools
